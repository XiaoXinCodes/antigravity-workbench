# 调试模式与本地日志

## 复现并保存

1. 从命令面板打开“Antigravity Workbench: 高级排障…”，选择“开启调试日志”
2. 重做一次失败操作，等到显示结果，再关闭调试模式
3. 点击“预览 / 导出日志”，查看只读的脱敏纯文本。之后点高级排障中的“保存已预览日志”或预览编辑器右上角的保存按钮，选择新的文件名。现有文件不会覆盖
4. 分享前再次检查内容；扩展不会上传日志或自动创建 Issue

每个窗口默认关闭，重载后也关闭。关闭立即停止接受新记录，之前已经接受的记录可完成落盘；旧日志保留。日志目录由当前扩展宿主的 VS Code 存储位置决定，高级排障可复制实际路径。只有路径兼容的本机宿主提供文件管理器入口；WSL 使用本发行版目录。

## 记录范围

只记录预先定义的操作、阶段、结果、错误码、耗时、版本、平台/宿主种类与随机操作关联 ID。进入图片发送阶段后，记录本次调用的 `imageEndpoint` 和固定 Google 主机名 `imageHost`；未进入发送阶段不伪造已发送主机。图片拒绝还会记录固定诊断枚举、是否放行调用，以及已知字段名和类型；未知字段只保留数量，不保留名称或值。

不采集原始日志、任意异常文本、标准输出/错误、完整 HTTP URL/头、邮箱、账号 ID、凭据、提示词、图片内容或用户路径。请求主机仅从 `daily` / `production` 固定枚举推导，不接受任意域名。诊断按白名单构造，预览时再次校验已保存行；未知或损坏内容不透传。日志中没有业务账号或真实任务 ID。

## 保存与限制

正常保留最多五个 64 KiB 文件，约 320 KiB；同宿主多个窗口分别写入并共享轮转上限，并发创建可短暂超出目标直到清理。手动导出的文件独立保留。日志缺失、被跳过或存储失败不影响业务操作，不代表业务一定成功。

发生存储权限或目录安全检查错误时停止写入，界面按读取、预览、选择位置和保存等阶段显示固定错误码与处理方式；修复权限后需重载窗口。不会自动降低保护或重建可疑目录。关闭状态不会创建日志文件。Windows ACL 与同一 OS 用户的恶意父目录替换仍有平台限制，日志不应视为防篡改审计记录。

日志相关测试覆盖字段过滤、轮转、多进程、取消与界面路由。自动化日志测试不执行真实账号登录或生图；当前验证范围见 [发行验证说明](VALIDATION_0.1.0.md)。


从命令面板打开“Antigravity Workbench: 高级排障…”，选择“诊断图片目录（不生图）”即可运行，无需先开启调试模式或打开工作台。命令主动显示工作台，在专门按需显示的图片目录诊断区域内显示查询中、目录对照或失败结果。查询最多等待 60 秒；未完成的取消不会允许重复请求。关闭工作台不会触发重试，重新打开可查看本窗口保留的结果。若工作台无法显示，查询不会开始，只显示一次安全的错误提示。该命令不生成图片，不自动打开日志文件，不开启日志记录。
