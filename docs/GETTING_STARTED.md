# Antigravity Workbench 使用指南

从 [最新 Release](https://github.com/XiaoXinCodes/antigravity-workbench/releases/latest) 的附件下载最新 `.vsix` 安装包，在目标 VS Code 窗口执行 **Extensions: Install from VSIX…** 并选择该文件。按提示重载后，在活动栏打开 Workbench。

Workbench 与 Google Antigravity 应运行在同一宿主；WSL 窗口应将 VSIX 安装到对应发行版，并使用该宿主中的扩展、CLI 和文件路径。

## 账号

1. 点击“添加账号”，确认后在系统浏览器选择 Google 账号并授权。插件保存新账号，然后恢复添加前的登录状态。
2. 直接在官方 Google Antigravity 登录后，Workbench 自动核验并显示当前身份、保存同宿主的加密副本，无需再点“保存当前”。返回窗口时立即检查；窗口内每五秒从本机 Hub 探测登录变化。相同身份保留原账号 ID 与标签。自动保存失败时保留已核实身份并显示错误，可用“保存当前”重试；本地副本完整性不证明 Google 仍接受授权。
3. 在已保存账号卡片上点击“切换”。插件自动识别本窗口后台，一次确认列出将停止的范围；确认后主动停止、执行切换、恢复后台并自动核验目标身份，通过后生效。
4. 在任一账号卡片点击“刷新”，查询并查看该账号的服务端模型额度与重置时间，无需先切换。查询进度、额度与错误直接显示在账号卡片，不另弹提醒；授权失效时可从卡片处理并重试。
5. 移除当前账号时，先安全切换至列表中首个同宿主且本地凭据可用的其他账号，核验成功后移除原副本；切换失败保留原副本。没有可用替代时只移除副本，保持官方登录。相同当前身份不会被后台立即重新保存；身份改变后恢复自动保存。

添加账号与切换账号是两个动作。切换可能中断确认范围中的活动任务，确认框会明确提醒；无需先手动结束后台。其他活跃窗口或无法核验的后台仅显示异常与恢复入口。操作未完成时保留恢复入口与必要备份；不要手动删除凭据或内部锁文件。取消授权网页不能撤销此前已批准的 Google 授权。

需要迁移已保存账号时，使用“导出账号 / 导入账号”并设置独立强密码。导入自动核验身份和额度，同邮箱可覆盖或跳过，当前官方登录不变，详见 [加密迁移](ACCOUNT_MIGRATION.md)。

## 图片

打开图片生成面板，默认“跟随当前登录”，也可选择其他已保存账号。选择已有账号后自动检查身份和图片模型，等待它自己的服务端模型返回，再填写提示词、比例和请求次数。选择生图账号不会切换官方当前登录；确认界面显示账号、模型、请求次数和保存目录，无需配置请求端点。

- 请求次数为 1–4 次，按顺序提交；每次响应可能包含多张图片。不会自动重试、切号或跨端点回退。
- 可选择最多 3 张 PNG / JPEG 参考图。尺寸与细节属于请求偏好，实际输出以服务返回为准。
- 默认保存到当前项目，也可选择当前宿主的其他目录；通过验证的 PNG/JPEG 会保存并提供预览。
- “恢复已有图片”从明确选定的官方会话中恢复 PNG，无需发送生图请求。
- 等待配置或确认时取消不会开始生成；已提交后取消仍可能计入服务使用额度。
- 草稿、所选账号与任务卡会在本机自动保存，重载后恢复。中断任务不会自动重发；删除任务记录不会删除已保存图片。

需要报告错误时使用错误码与操作记录，不反复提交来验证。更多参数与限制见 [图片说明](IMAGE_GENERATION.md)。

## 设置与反馈

高级排障设置与命令入口见 [设置与命令](COMMANDS.md)。

遇到问题时，从命令面板打开“Antigravity Workbench: 高级排障…”，可检查扩展运行位置；开启调试日志复现一次，再关闭，通过“预览 / 导出日志”检查并保存。提交 [Issue](https://github.com/XiaoXinCodes/antigravity-workbench/issues) 时附版本、系统、宿主、复现步骤和错误码，不附凭据文件或账号导出包。日志不会自动上传，详见 [日志说明](DEBUG_LOGS.md)。

图片工作室可对所选账号和模型点击“查询额度”，就地查看服务端剩余比例、重置时间与更新时间。再次查询或生成后的旧值会明确标记，不换算图片张数；详见 [图片额度](IMAGE_QUOTA.md)。插件常规选项使用工作台底部“设置”打开 VS Code 标准设置。

在工作台底部点“设置”，搜索 `antigravityAccounts.language`，手动选择 **简体中文**（默认）或 **English**。已打开的账号、图片和诊断视图即时更新，不重载，不清空草稿、参考图、账号选择或任务，也不触发登录和生图。命令面板及静态视图名称遵循 VS Code 显示语言，不能随插件设置即时改变；设置入口保留双语标签。未知设置值回退简体中文，工作区配置不覆盖用户级选择。
