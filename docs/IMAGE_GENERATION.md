# 图片生成、保存与恢复

图片面板提供独立的“生图账号”选择。默认“跟随当前登录”，也可使用本机已保存的其他账号。模型列表来自所选账号自己的服务端结果，正常使用无需配置请求端点。

## 调整工作区

宽窗口默认给输入区约 60% 宽度，结果区约 40%。拖动两栏之间的分隔条可调宽；双击恢复默认。分隔条获得焦点后，用左右方向键微调，Shift 加快，Home / End 到达边界，Enter 收起结果；拖动时按 Esc 撤销。

“收起结果 / 展开结果”只改变显示，不删除任务或图片。宽度与收起偏好会记住，窗口缩窄时自动上下排列；恢复宽窗口后继续使用原宽度偏好。输入区与结果区都有最小宽度保护。

## 生成一张图片

1. 在 Workbench 打开“图片生成”。默认账号需已保存并核验；也可在“生图账号”选择其他已保存账号。
2. 选择保存账号后，页面自动核验身份、project 和图片模型。等待它自己的模型目录返回，再选择模型、填写画面描述。不会从当前官方账号或聊天模型列表推测资格。
3. 选择比例、请求次数、尺寸与细节；需要时选择参考 PNG 和保存目录。
4. 点击“生成图片”，确认账号、模型、请求次数和输出目录。
5. 在对应任务卡等待保存完成，点击图片预览。每次生成独立显示提示词摘要、提交时间、模型参数和结果；再次生成不会覆盖前一次卡片。保存前会验证实际图片内容与格式。

## 生图账号与授权

选中 B 只改变图片页面的目标账号，官方当前登录 A、官方扩展和 CLI 凭据不变。任务确认显示实际账号；整批 1–4 次请求固定同一账号、模型、端点及参数。任务卡和已保存图片结果携带该账号关联。官方登录后续变化不会让运行中的任务转到别的号；失败不自动换号、降级或重发。

主动选择已有账号后，插件使用它已有的授权检查身份、project 和模型；必要时安全刷新并更新该账号的加密副本，不再增加“允许并检查”步骤。不会自动发起新 OAuth 登录或扩大服务 scope；授权撤销或无法安全刷新时，显示重新登录提示。每次生成仍有一次额度消耗确认。

尚未选择的保存账号不会被后台批量检查。账号检查整体最多等待 60 秒，超时、失败或取消后会显示明确状态，并提供原地重新检查，不因焦点变化或面板重开自动重试；迟到响应不会覆盖新选择。未知资格、过期授权、服务拒绝和已删除账号会显示处理提示；“重新检查此账号”主动绕过本窗口模型缓存。导入待核验或其他宿主的账号不能直接用于生图。选回账号时优先恢复它先前选择的可用模型，同时保留提示词、比例、尺寸和细节设置。同一宿主内重开面板保留选择，并复用最多五分钟且不超过令牌有效期的核验缓存；重载后恢复原生图账号选择，再检查其当前可用性；不可用时提示处理，不自动换号。账号记录被替换或变得不可用时停止使用，需主动重新选择。

当前版本使用虚构账号与 mock 响应验证当前登录和独立图片账号路径；真实 Google 服务授权、图片效果与额度以实际账号响应为准，详见 [验证范围](VALIDATION_0.0.8.md)。

## 参数

| 参数 | 支持值 | 说明 |
| --- | --- | --- |
| 宽高比 | `1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3` | 画面比例偏好 |
| 请求次数 | 1–4 | 顺序提交的生成请求数；一次响应可能返回多张图片 |
| 尺寸 | `auto`、`1K`、`2K`、`4K` | 请求偏好，不能保证实际像素尺寸 |
| 细节 | `auto`、`detail` | 请求偏好，实际结果由服务决定 |
| 参考图 | 最多 3 张本机 PNG | 选择时验证文件，不支持任意 URL 或 JPEG 参考图 |
| 保存目录 | 当前宿主可用目录 | 默认当前项目，也可更换；Windows 与 WSL 路径不能混用 |

界面为部分已知模型显示 Nano Banana 名称，同时保留真实模型 ID。名称不能证明账号拥有该模型权限；只有服务端提供的当前图片模型才能选择。

## 结果、取消与部分完成

返回的有效 PNG/JPEG 按实际格式保存到输出目录，使用新文件名。图片卡片展示已保存结果，点击后通过 VS Code 原生图片查看器打开。任务详情可收起。任务卡、已提交的完整参数及草稿保存在对应扩展宿主的私有工作区存储中，关闭面板、重载、重启和升级后恢复。草稿和任务快照仅保存在本机，不进入诊断日志；生成时所需提示词仍会发送给图片服务。未完成任务恢复为“已中断 / 结果未确认”，不会自动重发；图片文件缺失时保留记录并显示提示。任务详情中的“删除记录”只删除卡片，不删除图片。最多保留 200 张任务卡、总文件不超过 8 MiB；达到上限会停止新增并提示手动删除，不自动淘汰旧记录。存储失败时原记录保留，并停止新请求直到保存成功。

批量生成中途失败或取消，已验证并保存的图片仍可查看，后续请求停止。请求次数不等于保证产出张数。等待确认时取消不会提交；请求已发出后取消，服务端结果可能不确定，也可能已消耗额度。不会自动重试、切号或跨端点回退。

## 恢复已有图片

先选择输出目录，再点击“恢复已有图片（不生图）”，明确选择受支持官方会话目录中的 PNG。插件验证路径及图片后另存副本，不发生成请求，也不删除源文件。此入口不是任意文件浏览或全量会话迁移；当前恢复格式为 PNG。

## 操作记录与问题定位

“查看本机操作记录”列出本地记录的开始、结果、请求与保存数量和固定诊断字段。只有开始记录时，结果标为未确认；没有本机记录的任务不会被推断为成功。记录区可展开、收起，收起不删除记录，并保留当前窗口的展开状态。最近一次失败提示可帮助区分准备、请求、验证和保存阶段。

不能单凭 429 判定个人额度耗尽，HTTP 200 也不保证响应中有可保存图片。按 [故障排查](TROUBLESHOOTING.md) 提供错误码和操作编号即可；操作记录保留请求端点及主机，无需分享原始响应、提示词或凭据。端点覆盖仅用于 [高级排障](TROUBLESHOOTING.md#高级排障图片端点)。
