# 图片额度查询

图片工作室的「查询额度」只查询当前选中的生图账号和模型，不生成图片，不切换官方登录，也不启动新的 OAuth 登录。结果直接显示在账号和模型选择旁边，不打开文件，也没有成功弹窗。

每次点击都会请求该账号、该端点的 `fetchAvailableModels`，绕过本地五分钟模型目录缓存。只读取所选图片目录成员自身的 `quotaInfo.remainingFraction` 和 `quotaInfo.resetTime`，显示剩余百分比、重置时间和本次查询时间。字段缺失或无效时显示服务端未提供，合法的零值显示 0%。额度查询失败不会覆盖之前的成功结果；之前结果会明确标为旧值。

当前已核实的目录字段提供的是比例，没有独立可用图片张数或明确计量单位，因此不换算张数，不将订阅、AI credits 或账号卡片的 5 小时/周额度当作图片张数。也不按 `gemini` 前缀覆盖成一个公共桶。服务端未说明共享关系时，界面写明「服务端未说明」；目录成员资格不能证明还有额度，也不能证明模型实际可以生成。

所选保存账号的查询沿用既有身份、客户端绑定、加密刷新保存和同宿主锁机制。跟随当前登录时，读取并核验当前绑定，再向选中的图片服务发起目录查询。实际响应只提取上述白名单字段，账号 token 和 project 不进入 webview。保存账号授权过期时，既有安全刷新可能继续完成已开始的轮换保存；这不是新的登录授权。

账号、模型、端点变化、取消或关闭面板都会隔离旧请求。整个查询有 60 秒边界；迟到结果不会覆盖新选择。额度在本窗口内存中保存，不写入创作记录；生成开始后之前额度会标为旧值，下次需主动查询。

图片工作室的技术记录与失败详情收在默认折叠的「高级调试」中；工作台主界面不再显示运行环境或技术路径，目录诊断与日志导出通过命令面板「高级排障…」按需运行。显式运行目录诊断时仍会展开并显示进度、结果或错误，日志开关关闭也不会静默返回。

本轮只验证无凭证 mock 和隔离的扩展宿主。未验证真实账号响应中的图片额度字段、实际额度共享关系或生图调用资格。
