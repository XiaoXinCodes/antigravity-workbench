# 继续修改、版本对比与用进项目

本文介绍 0.1.0 的继续创作与项目操作。安装步骤见 [发行说明](RELEASE_0.1.0.md)，实际检查范围见 [验证说明](VALIDATION_0.1.1.md)。

## 继续修改

在已保存图片下点击“继续修改”，把这一张结果作为参考图，载入原任务的描述、账号、模型、比例、尺寸、细节、请求次数与保存位置。旧参考图列表会被替换，不会逐次累积。描述和参数仍可编辑；只有点击“生成图片”并确认，才会发送新图片请求。

被替换的草稿保存在本工作区的“保留草稿”中，最多 10 份。恢复时交换当前草稿；达到上限后要求手动整理，不会悄悄淘汰内容。删除保留草稿不删除任务或图片。存储失败会回滚草稿替换，并显示重试保存入口。

来源图片和新结果有独立文件，原图不覆盖。来源的账号、模型、图片摘要与父子关系随创作记录保存；来源文件变动后会阻止继续提交。单张参考图最多 8 MiB，最多 3 张、合计 16 MiB。PNG、JPEG 按实际 MIME 传入；已有图片超过参考图上限时仍可预览或用于项目。

原账号已删除、属于其他宿主、模型不可用或来源图缺失时，会就地说明问题。原模型不可用不会静默选择其他模型。主动更换账号或移除来源参考图后，本次按独立创作处理，不再显示为原版本的延续；不会自动切换官方登录或跨账号补发。恢复的历史图片若没有原账号与模型快照，不能假装复用原任务。

参考图请求可能改变其他画面内容，不保证精确局部编辑、像素一致性或透明背景。真实服务端编辑效果不在本次离线验收范围内。

## 版本对比

点击“版本对比”，分别选择来源和修改版本。宽窗口并排展示，窄窗口上下展示；不同原图的版本列表相互独立。部分完成的任务仅列出已经保存的图片并标注状态，失败、取消和中断任务不会被当作成功的新版本。

删除父任务记录不会删除原图，子任务仍保留来源关系。文件丢失或摘要不符时保留记录并显示原因，不用其他图片替代。删除任务仍仅删除记录，不删除任何图片。

## 用进项目

- **复制相对路径：** 相对于图片所属的工作区根目录，多根工作区会说明基准目录。不会凭空给路径添加工作区名称。
- **复制 Markdown：** 有可用目标文本文件时，相对于该文件所在目录；否则相对于图片所属工作区根目录，并明确提示基准。空格、中文、括号等字符按 URL 规则编码，图片说明中的 Markdown 特殊字符转义。
- **插入编辑器：** 仅在明确点击后替换所示文档的光标或选区，支持多个选区。保持未保存编辑，不自动保存，可一次撤销这次插入。面板获得焦点后保留目标；目标关闭、文件版本或选区过期、文档未保存、位于工作区外或只读时停止并提示。
- **复制到项目：** 工作区外图片需先明确选择项目内目标位置。保留原图、拒绝覆盖已有文件，不自动创建资源目录、修改框架导入、JSX 或构建配置。复制成功后，这条结果的项目引用操作使用副本；预览和继续修改仍使用原结果。副本被修改后要求重新核对。

文件操作在扩展所在宿主进行。支持本机文件 URI，以及能核对到当前 Linux WSL 发行版的 remote URI。其他 remote provider 的 URI 无法证明属于当前宿主时拒绝转换；不把远端路径当成本机路径。SSH、容器的实际项目操作尚未验证。

## 本机数据

正式 schema 1、云端扩展 schema 1 及早期本机 schema 2 加载后转换为 schema 3，保留草稿、参数、账号选择、任务、图片与项目副本引用。云端的 backup 草稿和父子关系也会保留；因旧记录没有来源图片摘要，沿用编辑前需重新点击来源图的“继续修改”，当下修改草稿会保留。加载不改原文件，只有后续安全保存才写新格式；损坏、未知格式或其他窗口已经更新的记录不会覆盖。旧候选不认识 schema 3 会拒绝读取，因此不要降级覆盖使用。

这些功能不删除账号凭据、官方会话或官方图片历史。验收范围见 [验证说明](VALIDATION_0.1.1.md)。

## 管理本次参考图

“添加参考图 / 替换参考图”选择最多三张 PNG 或 JPEG，并在描述下显示缩略图与数量。每张图可“移除”，也可“清空全部”；这只改变当前草稿引用，不删除原文件、任务历史或保留草稿。取消文件选择保持当前引用。

继续修改会把所选结果作为来源参考图。移除这张来源图或清空全部会解除本次版本关联；“独立创作（保留参考图）”只解除关联，仍保留引用。引用变更保存失败会恢复原状态并显示重试提示；保存成功后关闭、重开或重载仍维持更新结果。任务处理中不能修改引用。


图片页重载时会等待账号存储与官方 Hub 初始化，对明确的启动未就绪状态最多自动重查五次。恢复保存账号仍须匹配原记录；账号被替换、删除、授权失败或用户取消时停止自动恢复，可以手动重新检查。

完整成功且保存图片后，图片页对本次同一账号、模型和端点重新查询额度。查询失败保留带旧值标记的结果；读数超过一分钟也标为旧值。比例直接来自所选模型的服务端 `quotaInfo.remainingFraction`：缺失显示未知，真实 `1.0` 仍显示 `100.00%`，接近但未达到 `1.0` 的数值不会四舍五入成满额。此比例不代表可生成张数，也不证明额度独享或实时扣减。未获服务端图片目录确认的模型（包括 `gemini-nano-banana-2.1`）不会被静态添加。


账号列表与生图账号选择项只在核实官方身份且唯一匹配本宿主保存记录时，在名称后显示“（当前登录）”。选择另一账号独立生图不会改变此标注；身份未知、授权失效、恢复待处理或重复记录无法唯一匹配时不标。

模型目录查询的网络超时、明确可重试的网络错误和 HTTP 500/502/503/504 使用单独的临时错误分类，并在原账号、原端点上有界自动重查。鉴权、权限、格式错误、TLS 错误及无法分类的失败不会自动重试；用户取消、账号变化或关闭页面会停止。不会自动登录、切换账号、切换端点或重发生图。


首次保存账号查询若只是在等待普通账号操作锁，确认不存在恢复日志后按启动未就绪恢复；恢复日志存在或锁状态未知时继续阻止，不清锁、不绕过恢复流程。
