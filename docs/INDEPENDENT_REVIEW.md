## 独立复核证据

- `review_runtime` 重放生产 `automation-ui` 消息处理器：旧修订的测试／恢复／暂停／取消／删除均 `WAKE_TASK_CHANGED`，发送数为 0，最新 B／64 不变；保存排队后删除再释放，任务仍为 0。原生确认显示稳定别名，无邮箱。既有编译产物定向 39/39 通过；最新锚点后高级调度 13/13 通过。
- `review_history` 重放未知文案、历史模型缺失及 cron 原始复现。缺失原模型保持原值、`blocked:true`、生成数 0；未知文案正确；`*/1` 与 `*/2` 日期正确。既有编译产物定向 32/32 通过，最后 ISO 日期补丁另做只读静态复核。
- 独立审查确认原 `90c035b` 日志确为 1431 个测试／1427 通过／4 跳过／0 失败、四份 UI 收据 60 项全部通过；但原测试并未覆盖上表交错边界。本次新增回归和重新运行结果以最终交付收据为准。
- 新增跨独立进程的生产历史持久化回归：重复观察去重、清空与旧值回写并发后清空水位保留、账号删除后迟到观察与清理并发仍无历史残留。账号源是共享合成元数据，并非真实 VS Code 多窗口同步的端到端证明。

## 限制及未实施范围

五字段 cron 支持数字、通配、列表、范围、步长、月份／星期缩写及星期日 0／7；没有 Quartz 秒／年、L/W/#、宏或 shell crontab 语法。IANA 时区 DST 缺失时刻跳过、重复时刻只取较早一次，预览和执行共享算法。

真实 Google 对请求协议的接受、实际计费／额度变化、真实 WSL、正式 0.1.8 用户实机切号均未验收；用户切号成功反馈仍待收取。测试只用合成账号、合成凭据和内存传输。无推送、合并、发布或用户实机操作；SUL、版本和官方身份／进程／凭据轮换核心保持既有实现。跨进程合成测试不冒充真实多窗口账号元数据同步验收。
