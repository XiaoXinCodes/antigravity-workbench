# 本机功能验收

使用本人有权管理的账号，在实际目标宿主验证。测试前保存工作、结束官方任务；账号包、密码、令牌、私人提示词和原始日志留在本机。

| 项目 | 应观察的结果 |
| --- | --- |
| 启动 | 显示真实宿主；官方身份经核验后标注当前账号 |
| 添加账号 | 浏览器授权并保存新副本，随后恢复原登录并自动核验；添加不等于切换 |
| A→B→A | 每次确认后重启官方组件，目标服务端身份通过后显示当前；失败保留恢复入口 |
| 配额 | 结果在对应卡片显示，不为独立查询而切号；未知或失败不能显示为新的成功结果 |
| 取消与重复点击 | 操作串行，取消保留需要接续的记录；不自动重发图片请求 |
| 窗口恢复焦点 | 同一账号重新核验时不清空卡片、不提示换号；真正身份变化需要新证明 |
| 图片 | 单独确认后请求，核验实际文件、格式、尺寸与预览，分别记录成功和失败阶段 |
| 操作记录 | 可反复展开、收起，收起不删除内容；其他状态刷新不强行展开 |
| 已有图片恢复 | 明确选择受支持 PNG 后另存副本，无生成请求，源文件不变 |
| 登录恢复 | 只有原身份核验通过才完成；未知锁、外部变更及损坏记录保持保护 |

使用同一项目和用户配置检查已有会话与图片，对照文件及界面列表。不要为排查删除缓存、搬动会话或重写官方历史。缺项时先区分文件是否存在与列表是否显示。

跨设备迁移应分别验证每条 Windows / macOS / Linux / WSL 路径：导入不改变目标官方登录，副本待核验，首次切换失败可以恢复。一条路径成功不代表所有路径通过，见 [账号迁移](ACCOUNT_MIGRATION.md)。

使用“导出本机验收结果（不含账号凭据）”保存报告，只记录固定错误码与操作编号。事件只证明已记录的操作，不代表整份清单通过。已执行和未执行范围见 [验证说明](VALIDATION_0.1.1.md)。
