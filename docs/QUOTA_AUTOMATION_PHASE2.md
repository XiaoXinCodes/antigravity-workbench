# 第二批：可选定时请求、额度提醒与身份隐藏

> 以下记录保留各阶段当时的版本与验收范围；0.1.9 正式交付见 [发布说明](RELEASE_0.1.9.md)及[验证范围](VALIDATION_0.1.9.md)。

基于第一批本地提交 `7511649`，版本仍为正式 `0.1.8`；本批独立本地提交，不推送、合并、打包、发布或安装到用户实机。第二批按父线程补充授权实现可选定时请求。所有真实请求测试均使用合成账号与内存 HTTPS 传输，不能替代 Google 服务端或 WSL 验收。

## 用户功能与已实现范围

工作台新增“管理定时请求与提醒”入口，中文默认、手动切换 English。账号总览、收藏、QuickPick 和置顶状态栏沿用第一批体系。

- **定时请求**：总开关、任务均默认关闭；每日、每周指定星期、同一天多个 `HH:mm` 时刻；IANA 时区；每个账号独立的模型目录和精确模型 ID；下一次及后续五次预览；编辑、启用、暂停、取消、删除；手动测试；每实例结果。新建或修改任务保存为暂停状态。
- **请求预算**：固定短输入 `Hi`，默认最大输出 8 token，可选 1–64。输出预算不代表全部费用上限；结果分别显示服务端实际输出和总 token，没返回就显示未知。首次启用或测试有一次真实费用确认，后续界面持续说明请求费用。不保证改变 Google 额度重置周期。
- **额度提醒**：低额度、耗尽、服务端确认恢复均默认关闭，阈值 1–99%。账号额度和所选图片模型额度共享规则。首次观察建立基线，仅新鲜、绑定同一身份、更新观察时间的数据变化可提醒；服务端数据离开低额度区域（高于阈值）才算恢复，倒计时到零不触发。
- **身份隐藏**：用户全局设置及界面开关，稳定账号别名；覆盖账号卡片及提示、账号选择、任务与结果、图片页与历史、原生 QuickPick、状态栏及 tooltip。中英切换保持别名后缀一致。内部账号 ID、身份核对、凭据和用户填写的提示词不改写；保存文件、用户输入、用户目录路径及导出档案不是脱敏导出功能。

**本批未实现**：间隔、cron、按额度完全恢复触发。界面没有这些模式的空按钮，也没有自动推断模型池、自动切当前账号、自动启动官方后台或新 OAuth 登录。

## 调度与数据边界

预览和执行统一调用 `wakeOccurrences`；按所选时区日历计算，DST 缺失时刻跳过、重复小时只运行较早一次。VS Code 关闭时不运行；开启或恢复不会补发关闭期间任务；超过五分钟迟到跳过并安排下一个未来时刻。

私有状态采用验证后读取、0600 临时文件、fsync/原子替换及已有 `LiveLocks` 机制的独立状态目录。跨窗口重新读取后原子认领；实例 ID、修订、随机所有权 nonce、两分钟执行租约在发送前持久化。所有窗口与账号共享一个执行槽，最多 50 个任务，每任务最多 12 个时刻；占用时未认领任务保留到期时间。状态写入遇到活跃锁仅有限等待两秒，不按时间推断锁过期。

发送前再次检查任务修订、账号指纹、取消和迟到，并落盘“已发送”；不重试、重定向或补发同一个实例。发送后断连、超时、取消或身份替换记为未知并暂停任务；崩溃遗留的已发送实例到租约边界后同样变为未知。准备期遗留实例跳过。删除任务仍保留历史结果。未知实例永不自动重发，重新启用只安排未来时刻。

每次发送前重新读取该账号的模型目录，不用另一个账号或当前官方账号的目录。保留陌生模型，排除服务端显式图片专用 ID，不把额度桶当可调用模型。令牌只在扩展宿主内存，调度状态、消息和历史不保存 bearer 或 refresh token。

凭据访问抽出原生图模块的保存账号适配器，原有轮换的 stage/commit 及恢复锁未改变。会产生费用的发送位于元数据验证事务之外，防止其身份验证重试重复发送。调度在原有凭据锁内只读已运行官方 Hub 的当前身份；无法确认当前身份时禁止所有保存凭据轮换，当前官方账号始终不走第二条轮换路径。未过期保存凭据仍可独立读取；过期且不能安全轮换时需用户手动处理。没有调用 `activate`、启动进程、切号或写官方存储。

提醒先在同一原子状态中保存边沿，再显示通知，跨窗口、重复刷新及迟到旧数据不会重复通知。失败、未知、过期、禁用模型及身份替换不推断恢复。提醒只观察已有手动查询，不额外轮询额度。
