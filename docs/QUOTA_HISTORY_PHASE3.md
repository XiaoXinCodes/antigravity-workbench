# 第三批：额度观察历史与历史请求复用

> 本候选已删除图片页跨账号模型额度比较与推荐；图片账号选择、所选账号额度查询和既有历史仍保留。下列测试数字记录原阶段验收。

> 以下记录保留各阶段当时的版本与验收范围；0.1.9 正式交付见 [发布说明](RELEASE_0.1.9.md)及[验证范围](VALIDATION_0.1.9.md)。

基于前两批本地提交独立实现；保留 0.1.8 版本和现有 SUL。没有复制 Cockpit 代码、硬编码模型家族池或推算池 ID。

- 原先已有结果继续编辑、来源摘要、版本比较、草稿恢复、任务删除。新增任意有请求参数的历史任务复用，支持失败、取消、部分成功和中断；不另建任务体系。仅载入，手动生成和原有确认仍生效。
- 复用保存最新尚未自动落盘的当前表单为既有受保护草稿；10 份上限、保存失败回滚。保留原参考图列表，缺失／不可读明确提示，生成时仍必须通过原校验。原账号删除、替换或端点改变会阻止复用。新任务记账号元数据摘要；旧任务缺摘要时可检测账号捕获时间晚于请求的替换，不能追溯证明所有旧记录身份。
- 独立持久化实际服务端额度观察：账号桶与图片端点／模型使用不同类型和精确键；原观察时间保留。未知值不画成零，失败无新观察时间和值。散点和失败标记，不画连续消耗线，也不补采样。
- 账号、类型、系列、时间筛选；键盘选择散点和明细分页。保留 1–90 天（默认 30）、最多 5000 行，完整状态低于 1.5 MiB；删除／替换账号清除旧身份数据。清理保留去重水位，避免旧缓存复活。
- 全局可选身份隐藏、手动中英切换适用于新界面，正常界面不加入诊断墙。

验证：`npm run check` 1417 个测试，1413 通过，4 个 Windows 平台跳过，0 失败；新增 6 个历史／推荐核心测试和 2 个历史复用测试。隔离 VS Code 1.141 使用合成账号和本地目录，不读取真实凭据，不发 Google 请求，不切换官方账号。真实 UI 共 13 项检查通过，窄栏宽度 260px（内容 245px，无溢出）；证据在 `.test-results/history-ui-host`（结果文件、截图和宿主日志），独立脚本 `npm run test:history-host`。这不代表真实 Google / WSL 或 0.1.8 实机切换验收。

高级唤醒（间隔、cron、服务端满额恢复触发）在后续独立提交；本批不把原日／周历称作完整 Cockpit 功能。
