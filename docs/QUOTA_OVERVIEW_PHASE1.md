## 额度与身份约束

- 未提供或非法 fraction 显示未知，不转成 0%；明确 0 显示 `0.00%`，99.6% 显示 `99.60%`。只有真实 1 显示 `100.00%`；四舍五入会到 100 的未满值显示“接近 100%（未满）”。绝对积分与 disabled 单独展示。
- 仅接纳与当前卡片邮箱绑定的服务端快照。查询时间保留成功查询原始 observedAt；60 秒、非法/未来时间、加载中或失败后的旧快照均标旧数据。时间显示年月日、时分秒。成功刷新不弹窗。
- 服务端 bucket ID 是额度身份，不是可调用模型 ID。跨账号比较只使用服务端实际给出的 bucket/group/window；不按相同 fraction/reset 或标签推断 pool。
- 没有服务端 ID、ID 重复或未识别家族的行全部保留。缺 ID 的收藏限本账号；重复 ID 的行分别保留，但不参与跨账号按具体额度项比较。五种排序始终可手动选择；全部额度项按各账号最低已知 fraction 或最早已知 reset 排序，未知值排最后，全部未知时保持保存顺序。该排序不推断共享 pool，也不计算混合模型平均值。刷新、短暂缺数据和 webview 重建保留用户选择。
- 账号元数据版本绑定查询、队列和置顶：同 ID 的账号被替换、重绑或删除时，旧成功/失败不写进新卡片；等待锁时已替换的目标不启动请求。置顶变更明确显示失效，用户可取消置顶。
- 批量操作只有手动触发；最多 50 个当前宿主账号、并发 1、按保存顺序、去重、可取消、跳过变化目标。继续调用现有 `live.quota`，沿用凭据 stage/commit 与操作锁。取消停止后续队列；当前凭据轮换必须安全结束后才释放锁。不会切换当前官方账号。
- 15 秒定时器仅重绘旧值标记及状态栏，不发额度或生成请求。未加入自动唤醒或账号轮换。

## 交互验证与复现

`npm run check` 覆盖类型检查、lint 和所有既有/新增单元及集成回归。本环境最终结果：1391 项，1387 通过、4 项按原有平台/条件跳过，0 失败；类型检查与 lint 通过。

`DISPLAY=:<隔离显示> AG_VSCODE_TEST_VERSION=1.141.0 npm run test:quota-host` 启动临时 VS Code 用户数据/扩展目录，仅加载独立合成测试扩展。它直接使用生产 WorkbenchView、QuickPick/状态栏工具和图片界面，后端为可控制的合成账号适配器；测试通过 CDP 的真实鼠标/键盘事件操作。测试扩展没有加载 Workbench 真实账号后端或 Google 官方扩展，也没有真实生成、凭据或官方账号切换。结果、截图和 VS Code 日志保存在 `.test-results/quota-ui-host/`。

实操项目包含搜索/模型比较/未知排序、键盘折叠、成功/失败刷新、焦点及滚动保留、未变卡片节点保留、重复批量点击、取消、账号替换迟到结果、QuickPick 搜索保留/Enter 置顶/刷新取消/关闭、状态栏取消置顶、手动中英切换、240 像素英文侧栏、图片模型收藏且不生成。

本次隔离 VS Code 1.141.0 / Linux 实操 16 项全部通过，结果 `result.json` 标记 `passed: true`，240 像素 webview 的 scrollWidth/clientWidth 都为 225（包含垂直滚动条后的可用宽度），没有横向溢出。截图为实际运行的合成界面，不能替代真实账号验证。

此外，`npm run test:host` 验证真实扩展在临时配置中激活、注册命令、打开侧栏与图片面板、帮助及语言切换。它不构成真实 Google 登录/切换或 WSL 验收。当前 0.1.8 真实账号切换仍未收到用户成功验收。

云端默认沙箱将 `/` 的属主映射为 uid 65534，原有私有存储测试因此在祖先属主检查处失败；默认 umask 077 也会使权限拒绝样本的 0644 被收窄为 0600。全量复核在经自动审批允许的真实文件元数据环境、umask 022 下执行，未修改或放宽生产权限校验。

## 后续差距与设计（本批未提供占位按钮）

| 功能 | 已有/差距 | 下一批约束 |
| --- | --- | --- |
| 低额度、耗尽、恢复提醒 | 没有统一提醒状态机 | 默认关闭；明确阈值；以精确模型/额度身份和新鲜服务端观测驱动，失败/未知/旧值不推断恢复；跨窗口去重，用户可静音 |
| 唤醒调度 | 无实现 | 默认关闭。先明确账号、可调用模型、时区、消耗/输出上限与取消语义；独立持久化执行记录，防跨窗口重复。不能把额度 bucket 当模型 ID，不能把发出请求或超时当已推进周期；不自动切号、不盲目重试 |
| 生图账号推荐 | 可读取保存账号真实模型目录/额度 | 只比较用户真实所选 image model ID、枚举及 endpoint 对应的新鲜额度；能力缺失/未知/旧值不可推荐为有额度；展示推荐依据，由用户手动选择，绝不自动切号 |
| 额度历史曲线 | 未持久化时间序列 | 保留成功服务端查询原始 observedAt 和准确模型/额度身份；失败不插成功点，分离模型及窗口，标明过期与缺测；设置容量/保留期与本地删除 |
| 历史任务复用 | 已有任务卡片、草稿恢复、结果继续编辑、图片版本比较 | 补任意历史任务参数复用；复用前检查原参考图，缺失或不可读明确提示并等待用户处理；不虚构参考图，不直接生成 |
| 统一隐藏身份 | 无统一设置 | 可选并默认关闭；统一覆盖账号页、图片选择、QuickPick、状态栏及提示；不改变内部准确身份绑定；明确截图/导出范围 |
