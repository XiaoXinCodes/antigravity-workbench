# Antigravity Workbench 0.1.13

## 简体中文

模型与 Token 记录、用量概览和记录列表集中在同一页。

- 手动读取本机记录，首次显示全部已读记录；刷新保留筛选选择。
- 按时间、返回模型和项目筛选，查看每日趋势并导出 CSV / JSON。
- 时段为空时提示原因并提供“查看全部”；窄窗口下列表保持清晰可读。
- 图片和定时任务详情保留服务端提供的返回型号；改善定时任务结果保存。
- 更新中英文使用说明和界面截图。升级保留账号、图片历史、收藏、草稿及定时任务。

服务端未提供的 Token 或型号显示“未提供”。返回型号是服务端声明，不能证明底层实际模型。读取与导出不会发送模型请求。

## English

See model and token records, usage totals and the record list together on one page.

- Read local records on demand, starting with all read records; refresh preserves filters.
- Filter by time, returned model and project, inspect daily trends and export CSV / JSON.
- Restore the list from an empty period with **View all records**; keep records readable in narrow windows.
- Retain server-provided returned models in image and scheduled-task details; improve scheduled-result saving.
- Update both READMEs and screenshots. Upgrades preserve accounts, image history, favorites, drafts and scheduled tasks.

Missing tokens or models remain **Not provided**. Returned models are server declarations and cannot prove the underlying model. Reading and exporting send no model requests.
