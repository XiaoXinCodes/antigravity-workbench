Antigravity Workbench 是独立的非官方扩展，项目自有部分采用 [MIT License](../LICENSE)，随包第三方代码保留[独立许可](../THIRD_PARTY_NOTICES.txt)。服务条款与第三方接口限制见 [项目与服务说明](PROJECT_NOTICES.md)。本机保护措施不代表获得服务方授权或保证持续兼容。

疑似漏洞的报告方式见根目录 [安全报告流程](../SECURITY.md)；本页说明实现中的保护和限制。

## 账号与恢复

账号副本、恢复记录和待核验的授权更新使用 VS Code SecretStorage。标签、邮箱和时间等显示元数据保存在本机普通状态中，不应当作匿名数据分享。保护强度依赖 VS Code 与系统密钥库，不能抵御同一 OS 用户下的所有恶意扩展或进程。

OAuth 添加和切换先备份并核验原登录，按实际宿主选择受支持的存储路由。写入、后台停止、组件重启和服务端身份核验受同一事务约束；未知、冲突或不完整状态保留恢复记录。点击确认、缓存邮箱或成功写文件都不能代替服务端核验。见 [切换与恢复](ACCOUNT_SWITCHING.md)。

原生系统可能使用密钥库与文件槽；WSL 仅在当前后台文件路由获得证明后使用文件模式。恢复记录绑定宿主，不能复制 Windows 凭据到 WSL。程序不删除官方会话、图片或项目历史；官方组件自身的存储与认证生命周期另有边界。

系统工具使用固定目标和受控参数，秘密经标准输入传递，不进入命令参数、环境、webview 或原始错误输出。临时凭据文件可能因崩溃残留，应视为敏感内容。互斥不能冻结其他进程；不确定的锁和外部写入不会被强行覆盖。

## 配额与授权更新

当前账号优先通过官方后台查询。其他保存账号取得本机授权后独立查询，支持的授权更新仅访问固定 Google 端点，不切换当前登录，不轮试 OAuth 客户端。

轮换令牌先存入加密待核验记录，服务端身份通过后再更新对应保存副本。提交后取消不能保证 Google 没有执行；共享同一授权的其他客户端可能受远端轮换影响。见 [服务端配额](INDEPENDENT_ACCOUNT_QUOTA.md) 和 [授权更新契约](OAUTH_REFRESH.md)。

## 图片与日志

图片请求固定当前账号、模型、project 和端点，在确认范围内顺序提交，不自动重试、切号或跨端点回退。按实际 PNG/JPEG 内容验证响应，使用新文件名保存并读回检查。已有图片恢复只复制明确选择且通过检查的 PNG，保留原文件。见 [图片生成](IMAGE_GENERATION.md)。

调试日志使用固定字段与有界错误分类，不保存完整令牌、请求、提示词或原始响应。过滤不能替代导出前检查，日志不会自动上传。见 [日志说明](DEBUG_LOGS.md)。

## 快照与迁移

CLI 快照仅保留白名单身份和额度字段，不是签名凭据或当前登录证明。数据位于扩展 globalStorage 的 `metadata/accounts.json` 与 `snapshots/<sha256>.json`；身份哈希文件名不构成匿名化。读写检查大小、路径、文件类型、私有目录与并发锁，见 [快照采集](INTEGRATION.md)。

迁移包使用固定成本 scrypt 与 AES-256-GCM，密码不持久化。导入先核验候选身份和额度，再新增或覆盖明确选择的同邮箱账号；当前官方登录保持不变。导出只读保存副本，不修复或修改账号状态。包与密码持有人能够解密登录材料。见 [导出账号与导入账号](ACCOUNT_MIGRATION.md)。

## 不保证的范围

- 不保证阻止同一用户的恶意进程、父目录替换竞态或操作系统备份泄露。
- Windows 文件遵循现有用户目录 ACL，没有额外的完整 ACL 强化保证。
- 本地快照和缓存不能证明服务端当前额度，重置时间到达不能推断额度已恢复。
- 单机真实操作与隔离 CI 均不能证明所有设备、账号或长期服务稳定性。

报告问题只提供固定错误码与脱敏复现，不上传登录文件、账号包、SecretStorage 数据库或官方原始日志。
