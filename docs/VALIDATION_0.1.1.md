# 0.1.1 验证范围

账号、Hub、凭据与图片服务回归使用虚构数据、mock 响应及本地演示图，不访问真实 Google 账号、不生成真实图片。

- `npm run check` 执行类型检查、lint 和完整回归；发布门禁在 Linux、Windows、macOS 上执行相同命令，并运行隔离实际 VS Code 宿主、打包和许可检查。
- 新增进程回归核对当前宿主、UID、可执行文件、唯一 Hub 参数、端口与启动身份；覆盖外部 Hub、CLI、PID 复用、读取期间身份变化、延迟退出、退出超时及连续受控重启。
- 登录进度回归覆盖授权结束后延迟核验、尚未完成存储、保存后列表刷新、延迟第二次核验、取消后的晚到结果、身份请求失败与恢复记录被替换。仅使用 mock；未从浏览器画面推断服务端授权成功，也未绕过 Google 本人验证。
- 官方身份同步回归覆盖同 Hub 的外部账号变化、五秒本机探测、退出、身份去重、新授权更新、保存失败仍显示身份及旧添加记录保留。移除回归覆盖先切换后删除、无替代不切换、失败保留、同身份抑制、快速重新登录及其他宿主同邮箱副本。自动恢复在停机前和写入前核对完整快照；官方外部状态与检查/停机之间无法建立跨进程原子事务，发现变化会停止后续写入。
- macOS / Windows 回退分支保留原有进程枚举和排他检查。云端先用分支模拟验证，真实平台结果以对应 CI 作业为准。
- `python test/release-safety.test.py` 使用虚构发布数据验证拒绝路径，不写入网络、标签或资产；实际发布脚本只为新版本创建并核验资产，不覆盖已有正式版本。
- 云端默认根目录属于 UID 65534，原有私有日志检查会拒绝该目录链。完整离线检查在临时、断网的用户命名空间中运行；宿主权限、生产安全策略、文件元数据及断言均未修改。真实 CI 不使用该云端夹具。
- 包校验核对全部运行模块、源归档、版本、SUL 与第三方许可；正式字节与提交以随 Release 的 `release-manifest.json` 和 `SHA256SUMS` 为准。

## 边界

此版改善进程识别和 Workbench 发起的受控停机等待，没有修复官方组件启动期的孤儿 Hub 根因。没有已核实的官方导出任务活跃性查询，不会将父进程退出、低 CPU 或监听端口当作空闲证明，也不会自动终止未知外部 Hub。

十秒退出等待在官方停机钩子返回后开始，不覆盖钩子本身挂起。真实 Google 账号完整切号和真实生图尚未作为发布验收；人工结束已定位旧后台不等于补丁实机验收。SSH / 容器宿主尚未核验。
