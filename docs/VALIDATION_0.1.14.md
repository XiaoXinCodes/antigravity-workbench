# 0.1.14 验证范围

本版覆盖统一导航和编辑器复用、账号与额度、图片工作室、模型与 Token、定时请求、提醒、设置、帮助与高级排障。使用独立 VS Code 测试配置、虚构账号及离线适配器，验证中文／English、深浅色和高对比度、宽／窄窗口、键盘操作、草稿与筛选保留、自动读取与状态反馈。README 截图均来自这些合成页面。

首次目录读取在相同合成启动锁下进行修前／修后对照：旧版首次失败（LIVE_OPERATION_OR_RECOVERY_LOCKED，lock 阶段），初始化结束后仍需手动刷新；本版显示准备状态，就绪后自动成功。验证等待取消、重新打开、账号／端点变化及迟到响应隔离；不清理活动锁，不自动重试真实身份、HTTP 或解析失败。

用户提供的原始失败截图未捕获具体错误码，因此仅确认已复现并修复的初始化冲突，不声称已完成其真实账号现场验收。未读取真实凭据或用户对话，不发送 Google 生成请求。实际服务端权限与模型可用性仍取决于账号。

版本清单、锁文件、请求标识、CI 打包路径与发布校验统一为 0.1.14。正式资产由合并后的 main 提交构建，运行模块、文档、README 图片和源码包逐字节核对，SHA256SUMS 与 release-manifest.json 随正式 Release 提供。三个原生平台的最终 CI 结果以 GitHub Actions 对应提交为准。
